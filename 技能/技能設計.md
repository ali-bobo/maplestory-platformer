## Z — 三連飛鏢（Shuriken Triple）

| 項目 | 數值 |
|------|------|
| 解鎖等級 | Lv1 |
| 冷卻時間 | 0.5 秒 |
| MP 消耗 | 10 |
| 傷害倍率 | 1.2× ATK |
| 投射物數量 | 3 |
| 飛行速度 | 600 px/s |
| 最大射程 | 600ms（約 360px） |

### 視覺效果

1. **飛鏢旋轉**：每顆飛鏢旋轉 720° / 600ms
2. **能量拖尾**（rex PostFX 新增）：每顆飛鏢後方產生藍白色 `particle-dot` 拖尾，使用 `blendMode: ADD` 加亮
3. **飛鏢發光**（rex GlowFilter）：飛鏢本體施加 `GlowFilterPostFxPipeline`，intensity = 0.04，持續 500ms 漸弱
4. **暴擊閃光**：暴擊時觸發全畫面白閃（alpha 0.2, 80ms）
5. **鏡頭抖動**：命中時 50ms / 暴擊 100ms

### 音效

- 施放音效：`audio.playSkill('Z')`
- 命中音效：由 `particles.spawnHit()` 觸發

## 技術實作摘要

### rex PostFX Pipeline 使用

| Pipeline | 用途 | 註冊位置 |
|----------|------|---------|
| `GlowFilterPostFxPipeline` | 物件發光（飛鏢、能量球、分身） | `BootScene.create()` |
| `ShockwavePostFxPipeline` | 相機衝擊波（暗殺、漩渦） | `BootScene.create()` |

### VFX 工具模組 (`src/engine/vfx.js`)

| 函式 | 說明 |
|------|------|
| `flashGlow(scene, target, intensity, duration)` | 對任意 Game Object 施加漸弱發光 |
| `cameraShockwave(scene, worldX, worldY, duration)` | 以世界座標為中心的相機衝擊波 |
| `spawnEnergyTrail(scene, follower, color, duration)` | 跟隨物件的能量拖尾粒子 |
| `screenFlash(scene, duration, alpha)` | 全畫面白閃 |
| `energyBurstRing(scene, x, y, color, radius)` | 向外擴散的能量環 |

---

## 效能注意事項

- 粒子上限：建議同時存在 ≤ 250 個
- PostFX Pipeline：每個技能施放後會自動移除 pipeline，避免持續開銷
- `blendMode: ADD`：僅用於少量粒子，避免過度疊加導致 GPU 負擔
- 所有 VFX 函式使用 try-catch 包裹，pipeline 不支援時靜默跳過
