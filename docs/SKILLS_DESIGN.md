## 八、平衡數字（Phase 24：職業技能調校）

> 所有數字由 `src/engine/damageModel.js`（純函式）從 `constants.js` 的 JOBS / SKILLS 與 `config/skillModel.js` 的倍率表算出；
> `test/damageModel.test.js` 把設計意圖寫成斷言，`e2e/balance.cjs` 在遊戲裡實測。改倍率只改 `skillModel.js` / `statusEffects.js`，執行期和測試會一起變。

**怎麼讀**：單位都是「倍攻擊力」（1.0 = 一次 atk 的傷害）。單體期望 = 名義倍率 × 暴擊期望（基礎暴擊率 20%、暴擊倍率 ×1.8，加上職業被動）；毒和煙霧是持續傷害，不暴擊。
「參考隻數」是評估時假設會打到幾隻（單體技 1、暗影步伐 2、漩渦 / 赤月迴旋 / 迷煙彈 3）。影分身以 12 秒、7 成有目標估算。
斷命印記本身不傷人：它的價值 = 7 秒內普攻每一擊從「期望暴擊」變成「必暴擊 ×1.2」多出來的傷害。

### 8.2 設計意圖（調校目標，測試鎖定）

1. 專屬技能每 MP 傷害 ≥ 同職業繼承技能（三連飛鏢是 0.5 秒冷卻的補招，不在此列；用「參考隻數」評估）。
2. 傷害型專屬技能（瞬影連刺 / 毒鏢 / 印記 / 赤月迴旋）每冷卻秒傷害 ≥ 同職業繼承的爆發技（暗殺 / 漩渦 / 影分身）；毒鏢以疊滿 3 層的持續施放計。
3. 轉職後的普攻 DPS ≥ 盜賊普攻 ×1.3；刺客單體最高，俠盜靠 120 範圍與擊飛。
4. 定位：**刺客 = 單體爆發 / 暴擊 / 持續傷害**（瞬影連刺、毒、印記放大暴擊）；**俠盜 = 範圍 / 續戰 / 經濟 / 控場**（迴旋回血、妙手空空回 MP 與多金幣、迷煙彈減傷 + 定住 + 持續傷害）。
5. MP：四個技能都「冷卻一好就放」（不含補招 Z）至少撐 10 秒但不是無限（約 16～37 秒，視等級而定）；連 Z 一起連放約 10 秒見底。MP 每秒回 10。

### 8.4 MP 經濟

MP 上限 = 250 + 12 × (Lv-1)，自然回復每秒 10。下表是「這幾個技能冷卻一好就放」時，從滿 MP 撐幾秒（連放補招 Z 另計）：

- 刺客 Lv.12：暗影步伐 + 暗殺 + 瞬影連刺：**21 秒**
- 刺客 Lv.12：連三連飛鏢一起放（Z X C 瞬影連刺）：**10 秒**
- 刺客 Lv.24：暗殺 + 瞬影連刺 + 毒鏢 + 印記：**27 秒**
- 俠盜 Lv.12：步伐 + 漩渦 + 影分身 + 赤月迴旋：**16 秒**
- 俠盜 Lv.24：赤月迴旋 + 妙手空空 + 迷煙彈 + 影分身：**37 秒**
- 盜賊 Lv.20：步伐 + 暗殺 + 漩渦 + 影分身：**19 秒**

- 輪流施放四個技能能撐 16～37 秒，不會 10 秒就見底；一直連放會見底（要靠藥水或普攻補），沒有「放到永遠」的循環。
- 妙手空空每次命中回 10 MP，實際成本 14，是俠盜的續戰核心。

### 8.5 實測（`e2e/balance.cjs`）

遊戲內對靜止高血量靶，atk 固定 100、所有技能 1 級，每個技能連放數次取平均（倍攻擊力 / 施放）。實測有暴擊雜訊（單次標準差約 ±15%），
和模型的差在範圍內；腳本斷言：刺客普攻 > 盜賊 ×1.2、俠盜普攻 > 盜賊 ×1.15、瞬影連刺每 MP > 暗殺、赤月迴旋打 3 隻每 MP > 暗影漩渦、
印記期間普攻傷害 ≥ 1.4 倍（實測約 1.5～1.7 倍）、迷煙彈對 3 隻有實際傷害。
