# 內容路線圖 — 讓遊戲「更吸引人」

> 現況（Phase 20）：8 張地圖（含 1 張 Boss 房）、1 個職業（盜賊）、13 個任務、1 個副本、等級上限 30、5 個技能。
> 玩家玩到 Lv.20～30 就沒有新東西可追——卡在三件事：**地圖少、職業單一、沒有轉職這種「大目標」**。

這份文件分成：缺口分析 → 設計（轉職 / 地圖 / 特別任務）→ 需要的程式系統 → 建議開發順序。
美術清單在 [`ASSET_REQUEST.md`](ASSET_REQUEST.md)，可直接交給 AI 或畫師。

---

## 一、為什麼現在不夠吸引人

| 缺口 | 現況 | 玩家的感受 |
|------|------|-----------|
| 長期目標 | 只有「打到 Lv.30、打 Boss」 | 沒有「再努力一下就能變強 / 變不一樣」的里程碑 |
| 角色成長 | 技能只能加傷害（SP +1 = +12%） | 升級只是數字變大，玩法沒變 |
| 地圖 | 8 張，Lv.1～30 平均每 4 級才換一張圖 | 同一張圖刷太久、風格重複 |
| 任務 | 全是「打 N 隻」「到某地」 | 沒有劇情、沒有選擇、沒有特別獎勵 |
| 收集 / 重玩 | 裝備隨機掉落、副本每日 3 次 | 缺少「想刷某個東西」的理由 |

> 好消息：任務、副本、存檔、技能欄、NPC 對話、地圖資料表都已經是資料驅動，**新增內容主要是加資料 + 素材**，不用改架構。

## 二、轉職系統設計

### 2.1 流程（目標：玩家有 3 個明確里程碑）

```
Lv.1  盜賊（現有）
  │  Lv.10：一轉試煉  → 在「影之殿堂」找轉職官，完成試煉任務鏈
  ▼
 ┌───────────────┬───────────────────┐
 刺客（暗殺者）       俠盜（遊俠）
 暴擊 / 飛鏢 / 單體     近戰 / 連擊 / 範圍
 └───────┬───────┴─────────┬─────────┘
         │  Lv.30：二轉試煉（更難的任務鏈 + 副本）
         ▼
  影殺者  暗夜使者  |  盜賊王  暗影遊俠   （四個二轉職業，暫名）
         │  Lv.60：三轉 / 傳說任務（之後再做）
```

- 等級上限從 30 提高到 **50**（二轉後再往上）；`expNeeded`（100×Lv^1.45）與怪物數值都要隨之重平衡（見系統 7）。
- 一轉在 **Lv.10** 太早會讓新手沒有時間體驗基本技能；若覺得太早可改 Lv.15（可調，一個常數）。

### 2.2 一轉的兩個方向（差異必須「按起來不一樣」）

| 職業 | 定位 | 普通攻擊（空白鍵） | 專屬技能（取代 / 追加） | 被動 |
|------|------|------------------|----------------------|------|
| **刺客** | 單體爆發、暴擊 | 揮刀變成「兩連斬」，暴擊率 +10% | 影襲（瞬移背刺）、毒飛鏢（持續傷害）、致命標記 | 暴擊傷害 +30% |
| **俠盜** | 近戰連擊、群怪 | 揮刀範圍更大，第 3 下擊飛 | 迴旋斬（周圍範圍）、竊取（打中有機率掉額外金幣）、煙幕（敵人命中降低） | 最大 HP +20%、金幣掉落 +15% |

- 原本 5 個技能（Z X C V B）**保留為共通技能池**，轉職後再多 2～3 個職業專屬技能 → 技能池變 7～8 個、欄位仍是 4 格：**搭配成為玩法（build）**，這是目前「Lv.20 後 5 選 4」的自然延伸。

### 2.3 轉職任務鏈（特別任務的範本）

轉職官在新地圖「影之殿堂」（安全地圖）。每次轉職是 4 個步驟的任務鏈，有劇情、有選擇：

| 步驟 | 內容 | 需要的新機制 |
|------|------|-------------|
| 1. 對話 | 轉職官說明試煉，玩家**選擇方向**（刺客 / 俠盜） | 對話選項 UI |
| 2. 收集 | 到指定地圖打怪，收集 5 個「試煉之證」（任務專屬掉落） | 任務物品（collect 型任務） |
| 3. 挑戰 | 進入專屬副本「影之試煉」，限時擊敗試煉守衛（小 Boss） | 副本接任務、完成回報 |
| 4. 回報 | 回殿堂領取新職業、獎勵（武器 + 技能書 + SP） | 轉職資料寫入存檔 |

額外的「特別任務」（不影響轉職，純獎勵 / 劇情）：
- **失落的星光碎片**（劇情線）：跨地圖收集 5 塊碎片，每塊在不同地圖由 Boss / 小王掉落；集滿解鎖稱號 + 傳說武器。與教學裡「晨曦之星被擊碎」的故事呼應。
- **每日委託**：每天 3 個隨機討伐任務（存檔記錄日期），給金幣與強化材料。
- **NPC 好感支線**：每張新地圖 1 條 3 步驟的小故事（找物品 → 護送 → 擊敗頭目），給一件固定外觀 / 屬性的裝備。

## 三、地圖擴充設計

現有等級帶：浮空島嶼 1–5、森林獵場 5–12、古代廢墟 9–17、神秘之境（精靈）、台北都會 / 暗巷城 19–29、暗影領域 Boss。
**新增 6 張**，補在等級斷層，並刻意做出「風格差異」（音樂引擎已經支援每張地圖獨立調式 / 樂器，新地圖只要加曲目設定）：

| 地圖（暫名） | 等級 | 風格 | 怪物主題（每圖 5～6 種 + 1 小王） | 特色機制（程式端） |
|-------------|------|------|-------------------------------|------------------|
| **碧濤港** | 12–18 | 海港 / 海盜 | 螃蟹、水母、海盜幽靈、章魚、海鷗；小王：海盜船長 | 水面平台（較滑）、可上下的船桅 |
| **黃沙遺跡** | 16–22 | **沙漠** | 蠍子、沙蟲、木乃伊、仙人掌怪、沙盜；小王：沙塵巨蟲 | 流沙（減速區）、白天炎熱 / 夜晚（只換背景色） |
| **霜牙峰** | 20–26 | 冰雪山脈 | 雪人、冰狼、冰晶精靈、企鵝；小王：冰霜巨人 | 冰面地板（滑行）、暴風雪粒子 |
| **熔岩巢穴** | 26–32 | 火山 | 火焰精靈、岩漿史萊姆、炎犬、岩漿魔像；小王：熔岩龍 | 岩漿地板（持續傷害）、掉落的石塊 |
| **魔君王城** | 30–40 | **暗黑風** | 暗影騎士、惡魔、蝙蝠、吸血鬼；小王：墮落騎士團長 | 暗黑視野（暗角遮罩）、燭台可打 |
| **影之殿堂**（安全地圖） | — | 神殿 / 轉職 | 無怪物 | 轉職官、技能重置 NPC、轉職試煉副本入口 |

- 連接方式：晨曦鎮 ⇄ 浮空島嶼 → 森林 → 碧濤港 → 廢墟 → 黃沙遺跡 → 霜牙峰 → 熔岩巢穴 → 魔君王城 → 暗影領域（最終 Boss）。
  舊的「暗巷城 / 台北都會」改為城市支線（從晨曦鎮另開傳送門），避免主線過長。
- 每張新圖資料量 ≈ 一個 `MAPS` 條目 + 怪物 6 筆 + NPC 2 筆 + 任務 2～3 筆；測試 `test/content.test.js` 會檢查引用有沒有接錯（怪物 id、素材鍵、傳送門目標）。

## 五、建議開發順序

| 階段 | 做什麼 | 玩家得到 | 素材需求 |
|------|--------|---------|---------|
| **A（先做，不卡素材）** | 系統 1～3 + 轉職流程骨架（用現有 NPC / 怪物染色暫代） | 可以轉職、有選擇、有任務鏈的完整循環 | 無 |
| **B** | 補齊既有缺口素材（見素材文件 P0）+ 新地圖 2 張（碧濤港、黃沙遺跡）+ 專屬技能 | 兩個職業玩起來不一樣；中段不再重複刷同一張圖 | P0 + 2 張地圖包 |
| **C** | 剩餘 4 張地圖 + 二轉 + 特別任務（星光碎片、每日委託）+ 等級上限 50 | 長線目標 | 4 張地圖包 + 二轉角色圖 |
| **D** | 其他基礎職業、分數榜（需後端）、手機真機調校 | 重玩性、社群 | 每職業一整套 |

> 建議先給我 **P0 + 階段 B 的素材**；階段 A 我可以現在就開始，不用等素材。

## 六、需要你決定的事

1. **一轉等級**：Lv.10（建議）還是 Lv.15？
2. **職業名稱與世界觀**：刺客 / 俠盜 先用暫名，要不要改成跟「晨曦之星 / 暗影魔君」故事更貼的名字（例如「影行者」「星光守衛」）？
3. **是否要做其他基礎職業**（戰士 / 法師 / 弓箭手）：美術量是目前最大的，可先不做，等盜賊線完整後再決定。
4. **美術風格是否維持現有「楓之谷風手繪卡通」**：素材文件的 AI 提示詞以此為準。
