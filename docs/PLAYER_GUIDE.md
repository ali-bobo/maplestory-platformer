## 環境需求

- **Node.js 18 或以上**（用於 `npx serve` 啟動本地伺服器）
- **現代瀏覽器**：Chrome、Edge、Firefox 任一最新版（需支援 WebGL2）
- **約 10 MB 硬碟空間**（含 51 張遊戲圖片素材）

> Node.js 還沒裝？到 https://nodejs.org/ 下載 LTS 版即可。

## 30 秒上手

### ⭐ 最簡單：一鍵啟動腳本

clone 完直接執行對應的腳本：

| 系統 | 操作 |
|------|------|
| **Windows** | 雙擊 `play.bat` |
| **macOS / Linux** | 在終端機跑 `./play.sh`（首次可能要 `chmod +x play.sh`） |

腳本會檢查 Node.js、自動跑 `npx serve`、印出網址。

### 或手動指令

```bash
git clone <repo-url>
cd <repo 資料夾>
npm run play          # 等同 npx serve（綁定 127.0.0.1）
```

接著瀏覽器開啟 **http://localhost:3000** 就能玩。

**不需要 `npm install`**——`dist/bundle.js` 已預先打包進 repo，零依賴開玩。`npx serve` 首次執行會自動下載 `serve` 套件（< 30 秒），後續即時啟動。

**其他啟動方式**（任選其一即可）：

| 方式 | 指令 | 預設網址 |
|------|------|---------|
| Node.js | `npx serve .` | http://localhost:3000 |
| Python | `python -m http.server 8000` | http://localhost:8000 |
| VS Code | 右鍵 `index.html` → **Open with Live Server** | （插件分配） |

> **重要**：必須透過 HTTP server 開啟，**不能直接雙擊 `index.html`**（瀏覽器安全限制會把所有圖片擋掉，畫面會變成黑色方塊 + 綠色 X）。

## 操作說明

### 移動 / 跳躍 / 攻擊

| 按鍵 | 動作 |
|------|------|
| **← →** | 左右移動 |
| **↑**（或 **Q**） | 跳躍（空中可再跳一次） |
| **↓** | 站在薄平台上按住，穿透平台往下 |
| **空白鍵** | **普通攻擊**（近戰揮刀，不耗 MP，隨時可用） |

### 技能（四個欄位）

| 按鍵 | 欄位 |
|------|------|
| **Z** | 技能欄 1（盜賊預設：三連飛鏢） |
| **X** | 技能欄 2（預設：暗影步伐） |
| **C** | 技能欄 3（預設：暗殺） |
| **V** | 技能欄 4（預設：暗影漩渦） |

> 技能欄只有 **4 格**（Z X C V），技能卻有 5 個。全部解鎖（Lv.20）之後，可以**拖曳**畫面下方的技能圖示互換位置，或在技能視窗對沒裝備的技能按「**換入**」，自己決定帶哪 4 個。普通攻擊永遠在最左邊。

### 藥水快捷鍵

| 按鍵 | 藥水 |
|------|------|
| **A** | HP 藥水 |
| **S** | 強效 HP 藥水 |
| **D** | MP 藥水 |
| **R** | 強效 MP 藥水 |
| **G** | 萬靈藥（HP+MP） |

> 藥水原本第 4 格是 F，與 NPC 對話 F 衝突，改用 **R**。

### 互動

| 按鍵 | 動作 |
|------|------|
| **F** | 與 NPC 對話 / 接任務（靠近 NPC 時） |
| **M** | 開 / 關世界地圖 |
| **J** | 開 / 關任務日誌（進行中、可接取、已完成） |
| **ESC** | 一次只關**最上層**的東西：世界地圖 → 道具 / 裝備 / 技能 / 設定 / 任務視窗 → NPC 對話 / 商店；什麼都沒開時才開啟暫停選單（繼續遊戲 / 聲音開關 / 操作說明 / 存檔代碼 / 存檔回主選單 / **儲存並離開**） |
| **Enter** | 新手教學、對話中的「確認 / 繼續」 |
| 畫面右上 🔊 | 聲音開 / 關（音樂 + 音效，設定會記住；暫停選單裡也有） |

### 設定視窗

畫面右下的「**設定**」鈕（或手機點同一顆）打開設定視窗。設定存在瀏覽器的獨立欄位，**不會進存檔、也不會隨存檔代碼匯出**；按「重設設定」（再按一次確認）回到預設值。

| 項目 | 說明 |
|------|------|
| 音樂音量 / 音效音量 | 兩條滑桿（0–100%，預設 70 / 100）；手指或滑鼠拖動。音樂調到 0 會停止播放以省電 |
| 畫面震動 / 畫面閃光 | 關閉後攻擊、受擊、升級時鏡頭不再震動 / 閃白 |
| 傷害數字 | 關閉後怪物頭上不再跳出傷害數字 |
| 減少動態 | 一次關掉震動、閃光，以及低血量暈影的脈動與升級文字的彈跳（光敏 / 容易暈的人用） |
| 介面大小 | 小 / 標準 / 大，調整 HUD 與視窗的文字大小 |
| 存檔代碼 | 開啟存檔代碼視窗（見下方 Q4） |

視窗右側是按鍵對照表。

### 常駐目標列與任務日誌

畫面上方中央的一行字永遠告訴你「下一步」：進行中的任務會顯示進度（例如「擊敗果凍精 2/5」），目標在別張地圖時會加上「→ 地圖名」；沒有進行中任務時，指向最近的可接任務（「找島嶼義工說話，接任務「史萊姆獵手」」），再沒有就依主線給方向（練功地圖、守護者、星光之塔、暗影領域）。點它或按 **J** 開任務日誌。

### 受擊與回復

- 被怪物或 Boss 打到會**被擊退並短暫硬直**（Boss 與重擊退得更遠，伴隨畫面震動）；硬直遠短於無敵時間，不會被連續鎖死。「減少動態」開啟時震動與閃光會關掉。
- HP / MP **自然回復變慢**：受傷後 4 秒內不回血、施放技能後 2 秒內不回魔；城鎮等安全區回復快 6 倍。戰鬥中請靠藥水。
- 一般怪與小王血量提高（入門區不變，越後面越耐打），小王出招更頻繁。

### 儲存並離開

按 **ESC** 開暫停選單，點「**儲存並離開**」會先存檔再回到標題畫面，下次按「繼續遊戲」接關。在副本或 Boss 房中會先詢問，下次從安全的地圖重新開始。

### 低血量警告

- HP 低於 **25%**：畫面四周出現紅色邊緣暈影並呼吸閃動（開了「減少動態」就不閃，固定亮度）。
- HP **第一次**低於 30%（而且身上有裝備）：上方跳出一次提醒「倒下會失去身上所有裝備」。每個存檔只提醒一次。死亡的懲罰規則沒有改變。

## 第一次進遊戲會發生什麼

1. 進入主選單，點「開始遊戲」或按任意鍵
2. **第一次**會先看**新手教學**：晨曦大陸的故事（為什麼要打倒暗影魔君）、每個按鍵的功能、技能與任務系統介紹。**Enter** 下一頁、**←** 上一頁、**Esc** 跳過全部（手機點畫面繼續、點右上「跳過全部」）。之後想重看，到暫停選單點「操作說明」。
3. 角色出現在「**浮空島嶼**」（Lv1）—— 藍天白雲、淺色平台
4. 靠近 NPC 按 **F** 對話會接到任務，進度顯示在畫面右上角的**任務追蹤面板**（例如「擊殺 5 隻 slime」）
5. 用 **← →** 走動 + **↑** 跳上平台 + **空白鍵** 攻擊怪物
6. 殺滿任務需求數量 → 任務自動完成 + 發 EXP / 金幣 + 浮動提示
7. **練到一定等級會解鎖新技能**（Lv5 解影步伐、Lv10 暗殺、Lv15 暗影漩渦、Lv20 影分身）
8. 走到地圖**最右側**會看到 portal，走過去進入下一張地圖

**新手推薦動線**：浮空島嶼練到 Lv5–8 → 森林獵場 → 古代廢墟 → … → 暗巷城 → 累積 60 殺 → 挑戰 Boss。

## 地圖介紹

### 浮空島嶼
- **背景**：晴天浮空島，藍天白雲
- **怪物**：史萊姆、蘑菇、蝸牛、樹樁（Lv1–8）
- **推薦等級**：Lv1–10

### 森林獵場
- **背景**：綠意森林，草地與木質平台
- **怪物**：以蘑菇、樹樁等植物 / 菇類為主，搭配少量蝸牛、野豬
- **推薦等級**：Lv5–12

### 古代廢墟
- **背景**：沙漠廢墟，石拱遺跡
- **怪物**：以骷髏戰士、廢墟騎士為主，搭配少量魔像與巨人
- **推薦等級**：Lv9–20

### 神秘之境
- **背景**：彩色奇幻城區，作為城市區前的過渡地帶
- **怪物**：精靈、飛行與奇幻怪物為主（雲端精靈、浮雲鳥、擬態箱）
- **推薦等級**：Lv13–22

### 暗巷城
- **背景**：夜間城市，磚牆霓虹
- **怪物**：城市流氓、暗夜猛獸、擬態箱、少量龍與低頻率小王
- **推薦等級**：Lv18–30

### 台北都會（支線）
- **背景**：藍灰色都會天際線，較乾淨的高架平台輪廓
- **怪物**：機械衛士、機械直升機、精英衛兵與低頻率都會督軍
- **推薦等級**：Lv22–28
- **特殊**：可從神秘之境進入，也可從這裡返回主線

### 晨曦鎮（城鎮）
- **背景**：暖色玩具鎮，平靜無敵
- **內容**：NPC（商人、嚮導）、史萊姆洞窟副本入口
- **怪物**：無

> 目前怪物配置採 **主題式精選**：不是每張怪物圖都會同時上場，優先維持版面和諧、乾淨與地圖辨識度。

## 技能系統

| 欄位 / 鍵 | 技能 | 解鎖 | 冷卻 | MP | 說明 |
|---|------|------|------|-----|------|
| 空白鍵 | 普通攻擊（揮刀） | — | 0.4s | 0 | 面前短距離斬擊，範圍內的敵人都會受傷，不吃技能等級 |
| 預設 **Z** | 三連飛鏢 | Lv1 | 0.5s | 10 | 扇形連發 3 枚飛鏢，第 3 枚可穿透 2 隻；暴擊會擊退 |
| 預設 **X** | 暗影步伐 | Lv5 | 3s | 30 | 衝刺穿過敵人並留下標記，衝刺結束後標記同時引爆十字斬 |
| 預設 **C** | 暗殺 | Lv10 | 5s | 50 | 瞬移到最近敵人背後，兩下快斬接一記重擊，全段必定暴擊 |
| 預設 **V** | 暗影漩渦 | Lv15 | 8s | 70 | 在前方開出漩渦，持續把周圍怪物吸進中心並造成多段傷害，最後引爆擊飛 |
| 預設 **B** | 影分身 | Lv20 | 15s | 100 | 召喚黑影分身 12 秒，會自己跑去追怪：近身斬擊、遠距丟鏢，你普攻時也會跟著丟 |

> 技能隨等級自動解鎖。MP 會隨時間自動恢復，無需手動補。

**戰鬥小訣竅**：
- 群怪時優先用 **V**（範圍）+ **B**（持續輸出），單體 Boss 用 **C**（爆擊）+ **Z**（連射）；MP 見底時靠空白鍵普攻撐住
- **X** 也能用來閃避：朝相反方向衝刺脫離危險
- 別忘了 MP 上限會隨等級成長，前期省著用 V/B

## 角色成長與裝備

- **等級上限**：Lv30
- **升等加成**：HP +20、MP +12、ATK +5
- **裝備系統**：擊殺怪物有機率掉落武器、護甲、手套、頭盔、靴子
- **暴擊**：基礎暴擊率 20%，暴擊傷害 1.8 倍
- **EXP 條**：HUD 底部最下方一條細條
- **升級時機**：每次升等會全屏閃光提示，HP / MP 滿補

**裝備強化**：擊殺怪物自動撿取，HUD 會顯示獲得通知。同部位掉落時，新裝備會比較攻擊力 / 防禦力高低，由你決定是否替換（目前自動套用較強的）。

## Boss — 暗影魔君

**觸發條件**：集滿五塊星光碎片並點亮晨曦鎮的星光之塔後，才能進入最終 Boss 房。

| 階段 | HP 範圍 | 攻擊模式 |
|------|--------|---------|
| Phase 1 | 100%–70% | 地面衝擊、普通攻擊；大招前地面會出現預警區 |
| Phase 2 | 70%–35% | 新增暗影召喚（影子史萊姆）、更大範圍的攻擊，節奏變快 |
| Phase 3 | 35%–0% | 狂暴模式，攻擊更頻繁、範圍更大 |

最終 Boss 血量 32000。範圍招式（重擊、地面爆發等）出手前會在地面顯示和實際判定一樣大的**預警區**，看到就移動或跳開。

**攻略建議**：
- 進場前確保 HP / MP 滿、有 Lv15+ 的 V 與 Lv20+ 的 B 解鎖
- Phase 2 召出的影子史萊姆會干擾，優先用 V 清掉
- Phase 3 狂暴期間用 X 拉開距離，等冷卻好再用 C 切入

## 🆕 副本系統

**Phase 14 新增功能**——重複可玩的限時挑戰副本。

### 入口

晨曦鎮（town）中央有一個紫色傳送門「⚔ 史萊姆洞窟」。傳送門上方的文字會顯示**今日剩餘次數**：

```
⚔ 史萊姆洞窟（今日剩 3 次）
```

### 史萊姆洞窟（Slime Cave）

- **等級限制**：無（Lv1+ 都能進）
- **時間限制**：180 秒（3 分鐘）
- **目標**：清光三波怪物即可通關

**三波怪物**：
| 波次 | 內容 |
|------|------|
| 1 | 5 隻 slime |
| 2 | 6 隻 slime + 2 隻 shadow-slime |
| 3 | 4 隻 shadow-slime + 3 隻 mushroom |

### 獎勵

**通關**：
- 基礎：**+800 EXP**、**+1500 金幣**
- 時間加成：剩餘秒數 × 5 = 額外 EXP（例如剩 90 秒 → +450 EXP）

**失敗**（時間到或角色死亡）：
- 安慰獎：+50 EXP、+100 金幣

### 每日上限

- 每個副本**每天可進 3 次**，跨日自動歸零（依本機時間）
- 進入次數記錄在瀏覽器 localStorage（清除瀏覽器資料會洗掉次數記錄）
- 用完當天 3 次後，再踩傳送門會出現 toast「⚠ 今日已達上限，明日再來」，玩家留在 town

### 副本內 HUD

進入副本後，畫面上方中央會顯示：
```
【史萊姆洞窟】  波次 1/3  ⏱ 02:54
```
- 倒數 < 30 秒時計時器變紅
- 殺光當前波 → 1 秒後自動觸發下一波
- 殺光最後一波 → **勝利結算 popup**（按按鈕回 town，獎勵入帳）

## 📱 手機遊玩

用手機或平板的瀏覽器開遊戲網址即可，**請橫放**（直放時會提示轉橫）。偵測到觸控裝置時會自動出現操作層。預設是**虛擬搖桿**（左手移動、右手攻擊 / 技能），也可在「設定 → 觸控操作」切回**舊式按鈕**。

### 虛擬搖桿（預設）

- **左半邊螢幕任一處按住**，手指按下的位置會浮出一個圓形搖桿，放開就消失。
- 左右拖曳 = 左右移動（中間有死區，輕微抖動不會動）；**往下推** = 站在薄平台上穿過去（同「↓」）。
- **跳躍**：把搖桿頭**往上推**過一定距離就起跳（有「上推」▲ 記號）。
- **二段跳**（三種做法任選）：
  1. 在空中把搖桿**回到中央，再往上推**一次；
  2. 在空中**快速往上一滑**（不必推到頂）；
  3. 用**另一根手指點右側畫面任一處**，或按右下的「跳」鈕（右手拇指單點即可跳，空中再點一下就是二段跳）。
- 一直按住上推不會連續跳，要回中立再推才算下一跳，所以不會誤觸連跳。
- 斜著往右上推 = 邊跑邊跳。
- 左右互換鈕可把搖桿與按鈕對調（左撇子）。

| 位置 | 按鈕 | 功能 |
|------|------|------|
| 左半邊螢幕 | （浮動搖桿） | 移動、上推跳、下推穿平台 |
| 右側空白處 | 點一下 | 跳（含二段跳） |
| 右下 | 普攻 / 跳 | 普通攻擊（等於電腦的空白鍵）／跳躍 |
| 右側 | 四個技能鈕 | 對應 Z X C V 四個技能欄位，**字樣會跟著你排的技能變**（鎖定的會變暗） |
| 右側 | 互動 | 與 NPC 對話 / 開商店（同鍵盤 F） |
| 左上 | 暫停 | 開啟 / 關閉暫停選單（同鍵盤 ESC）；教學中等於「跳過全部」 |
| 左上 | 全螢幕 | 進入全螢幕（Android Chrome 會一併鎖定橫向） |
| 左上 | 左右互換 | 把搖桿與動作按鈕左右對調，設定會記住 |
| 畫面右上 | 🔊 | 聲音開 / 關 |

### 舊式按鈕（設定 → 觸控操作 → 舊式按鈕）

預設為**右手移動、左手攻擊**（跳躍與下穿跟移動在同一隻手）：

| 位置 | 按鈕 | 功能 |
|------|------|------|
| 右下 | 橫條（搖桿） | 左右移動：手指放在條上，往左 / 右滑 |
| 右下（搖桿上方） | 跳 / ↓ | 跳躍（可二段跳）／站在薄平台上按「↓」往下穿過 |
| 左下 | 普攻 | 普通攻擊（等於電腦的空白鍵） |
| 左側 | 四個技能鈕 | 對應 Z X C V 四個技能欄位，**字樣會跟著你排的技能變**（鎖定的會變暗） |
| 左側 | 互動 | 與 NPC 對話 / 開商店（同鍵盤 F） |
| 左上 | 暫停 / 全螢幕 / 左右互換 | 同上 |

- **藥水**沒有螢幕按鈕：直接**點畫面下方的藥水槽**（A / S / D / R / G）即可使用，電腦上也可以用滑鼠點。
- 可以**多指同時操作**，例如一手移動、一手跳躍和攻擊；每根手指各自追蹤，手指移出搖桿範圍、拖出螢幕邊緣、被系統打斷或切到背景時，搖桿都會正確放開，不會卡住一直跑。
- 畫面下方的道具 / 裝備 / 技能 / 任務 / 地圖 / 設定按鈕直接用手指點。
- 手機橫放時畫面縮得很小，遊戲會自動把 HUD 與視窗的文字放大；開著技能 / 裝備 / 設定等視窗、暫停選單或 NPC 對話時，**搖桿、跳躍、攻擊、技能鈕會暫時收起**，才點得到視窗上的「+」和「換入」，只留下暫停鈕。
- 四個技能鈕與普攻鈕有**冷卻掃描**（暗色圓扇順時針收起，中央顯示剩餘秒數）；MP 不夠施放的技能鈕會變灰。
- **iPhone / iPad**：Safari 不支援網頁全螢幕。請點「分享」→「加入主畫面」，從主畫面圖示開啟就會是無網址列的全螢幕。
- 第一次點擊 / 觸碰（手指放開）後才會有音樂與音效（瀏覽器限制）；iPhone 若仍沒聲音，請確認側邊靜音鍵沒有開啟，或點右上 🔊 確認沒有被關閉。
- 手機上預設使用「中」畫質；若仍卡頓，遊戲會依幀率自動降低特效。
- 電腦上想預覽觸控版面：網址後加 `?touch=1`；想關閉：`?touch=0`。

## 常見問題 FAQ

### Q1：圖片全部變黑色方塊 + 綠色 X
**A**：兩個可能原因：
1. 你直接雙擊 `index.html` 開啟 → **必須用 HTTP server**（`npx serve .`）
2. 瀏覽器 cache 過期 → 按 **Ctrl + Shift + R**（Windows / Linux）或 **⌘ + Shift + R**（macOS）強制重新整理

### Q2：副本進不去 / 一靠近 portal 就被擋回來
**A**：看 portal 上方標籤「今日剩 N 次」：
- 顯示 N > 0：應該能進，若仍進不去請開 F12 看 console error
- 顯示 N = 0：今日 3 次已用完，明天才能再進。如要立即重置可清除瀏覽器 localStorage（F12 → Application → Local Storage → 刪 `thief_legend_dungeon_daily_record`）

### Q3：按鍵沒反應
**A**：依序檢查：
1. 瀏覽器分頁是否 focused（點擊一下遊戲畫面）
2. 輸入法是否在英文模式（中文輸入法會吞掉空白鍵、Z/X/C/V 等按鍵）
3. 是否在 NPC 對話框內（先按 ESC 關掉）

### Q4：遊戲有存檔嗎？
**A**：有。遊戲會自動存到瀏覽器的 `localStorage`：進入一般地圖、升級、每 30 秒、從暫停選單「存檔並回主選單」、關閉或切走分頁時都會存。存檔內容：等級 / 經驗、屬性、裝備、藥水、金幣、技能與技能點、任務進度、目前地圖。

- **繼續**：主選單的「繼續遊戲」從上次存檔點開始（HP / MP 回滿，技能冷卻歸零）。副本與 Boss 戰中途不會存，離開時回到最近的安全地圖。
- **新遊戲**：有存檔時需連按兩次確認，會覆蓋目前存檔。
- **換瀏覽器 / 換電腦 / 內嵌頁面**：用**存檔代碼**。主選單的「匯出存檔」（遊戲中是暫停選單或設定視窗的「存檔代碼」）會顯示一串 `TL1:…` 文字，按「複製代碼」貼到備忘錄；在另一邊的主選單按「匯入存檔」貼上代碼。已有存檔時匯入會先顯示「目前的存檔 → 將被覆蓋成」並要你確認。剪貼簿被瀏覽器擋住時，代碼會被全選，自己按 Ctrl+C（手機長按選「拷貝」）。視窗裡也有「下載檔案 / 選擇檔案」，在能下載的瀏覽器可以用；內嵌或沙箱頁面通常下載不了，請用代碼。
- **清除瀏覽器資料會把存檔一起清掉**，重要進度請先複製存檔代碼。
- **「未存檔」**：隱私模式、內嵌頁面等寫不進瀏覽器儲存空間時，主選單與遊戲畫面上方會常駐紅色「未存檔」。這時進度只留在這個分頁的記憶體裡（同一分頁內仍可繼續、可匯出代碼），關掉頁面就沒了——點「未存檔」就能複製存檔代碼。
- 副本每日次數另外儲存，不包含在匯出的存檔裡。

### Q5：角色倒下會怎樣？
**A**：結算畫面會顯示**分數**（等級 × 100 + 擊殺數 × 10 + 金幣 ÷ 10，通關另加 5000）。按「從死亡點重新開始」會在死亡的地圖重生（副本 → 晨曦鎮、Boss 房 → 暗巷城），HP / MP 回滿，但**會失去身上所有裝備**；等級、經驗、金幣、技能、藥水、任務都保留。懲罰在死亡當下就寫入存檔，重開網頁也無法取回裝備。重生後有 3 秒保護時間（半透明閃爍、不受傷）。

### Q6：可以改難度嗎？
**A**：目前**沒有難度選項**。怪物攻擊力與血量寫在 `src/config/monsters.js`，要改要去動原始碼（看 README 的開發者區塊）。

### Q7：遊戲變卡 / 掉幀
**A**：遊戲有 **自適應品質系統**——FPS 連續低於門檻會自動降特效品質。如果還是卡：
- 關閉其他瀏覽器分頁
- 關閉背景應用程式（影片、串流軟體）
- 嘗試切換到 Chrome / Edge（WebGL 效能較好）
- F12 → Console 輸入 `__setFps(30)` 鎖 30 FPS（穩定優於流暢）

### Q8：可以全螢幕嗎？
**A**：目前**沒有內建全螢幕按鈕**。可以用瀏覽器的 **F11** 切全螢幕，但遊戲畫面是固定 1280×720，全螢幕會在四周留黑邊。

## Troubleshooting 疑難排解

### 圖片載入失敗（黑方塊 + 綠 X）
**症狀**：MenuScene 標題能顯示，但角色 / 怪物 / 背景全變黑方塊 + 綠 X，且「載入中... 請稍候」沒消失。

**診斷步驟**：
1. F12 → **Console** 分頁，找紅色 error 訊息
2. 若看到 `Content Security Policy directive` 阻擋 → 你應該透過 HTTP server 開啟（不是 file://）
3. 若 Network 分頁看到 `*.png` 404 → 確認 `dist/assets/` 目錄完整（應有 51 張 PNG）

### `port 3000 already in use`
**症狀**：執行 `npx serve .` 時抱怨 port 被佔用。

**解法**（任選）：
- 換 port：`npx serve . -l 3001` 然後開 http://localhost:3001
- 找出舊 process 殺掉：
  - **Linux / macOS**：`lsof -i :3000` 找到 PID → `kill <PID>`
  - **Windows**：`netstat -ano | findstr :3000` 找到 PID → `taskkill /PID <PID> /F`

### 音效沒聲音
**症狀**：戰鬥沒音效、跳躍沒聲。

**原因**：瀏覽器的 Web Audio API 預設靜音，需要使用者**先互動**（點擊 / 按鍵）才會啟用音訊。

**解法**：
1. 確認瀏覽器分頁沒被靜音（網址列旁有喇叭圖示）
2. 確認系統音量沒關
3. 在遊戲畫面點一下或按任意鍵後音效應該就有了

### CSP error 一直跳
**症狀**：F12 Console 一堆紅色 CSP violation。

**原因**：`index.html` 內的 CSP（Content Security Policy）meta tag 太嚴格，擋掉圖片或 inline script。**最新版本已修正**，含正確的 sha256 hash 與 `connect-src 'self'`。

**解法**：拉最新 `git pull`，或檢查 `index.html` 第 6 行 CSP 是否含 `'sha256-EFq...'` 與 `connect-src 'self'`。**請勿自己修改 CSP**，會破壞其他保護機制。

### 遊戲跑得慢 / 卡頓
**原因**：通常是 GPU fill rate 瓶頸（整合顯卡 + 1280×720 解析度）。

**解法**：
1. F12 Console 輸入 `__setFps(30)`：鎖 30 FPS（穩定的 30 比抖動的 50 順暢）
2. 等待自適應品質系統自動降級（觀察粒子減少、特效變樸素）
3. 換到桌機 / 獨立顯卡或更高效能設備

## 如何停止本地伺服器

關閉瀏覽器分頁**只會關掉遊戲畫面**，不會停止背景的伺服器。必須回到啟動伺服器的終端機手動終止：

| 啟動方式 | 停止方法 |
|---------|---------|
| `npx serve .` | 終端機按 **Ctrl + C**（macOS 也是 **Ctrl + C**） |
| `python -m http.server 8000` | 終端機按 **Ctrl + C** |
| VS Code Live Server | 點 VS Code 右下角狀態列的 **「Port: xxxx」**，或按 **Ctrl + Shift + P** → 輸入 **「Stop Live Server」** |

> **若忘記終止伺服器**，下次啟動時可能出現 `port already in use` 錯誤，請參考上面 [Troubleshooting](#port-3000-already-in-use) 找 PID 殺掉。
